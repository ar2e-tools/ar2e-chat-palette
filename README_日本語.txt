# アリアンロッド2E チャットパレット生成（iPhone向けWebアプリ）

## できること
- ゆとシートから出力したJSON／HTMLをiPhoneの「ファイル」アプリから読み込む
- アクティブスキルの宣言と数値MPコストを生成する
- 出力をコピー、またはテキストファイルとして保存する
- HTTPSで公開したあと、Safariの「ホーム画面に追加」でアプリのように起動する
- 一度読み込んだアプリ本体は、対応ブラウザでオフライン起動できるようキャッシュする

## iPhoneで使うまで
このZIPはWebアプリの一式です。iPhoneでHTMLファイルを直接開くのではなく、HTTPSのWebサイトとして一度公開する必要があります。こちらから直接Web公開することはできないため、以下のいずれかの静的ホスティング先へこのフォルダの中身をアップロードしてください。

1. GitHub Pagesなどの静的サイト公開サービスで新しいサイトを作る
2. このZIPを解凍し、中のファイル一式（`index.html`, `manifest.webmanifest`, `sw.js`, アイコン2つ）をサイトの公開フォルダに配置する
3. HTTPSのURLをiPhoneのSafariで開く
4. Safariの共有ボタン →「ホーム画面に追加」
5. 追加したアイコンから起動し、「ファイルを選択」でJSON／HTMLを読み込む

## プライバシー
キャラクターシートはブラウザ内で解析します。ページのコードからシート内容を外部へ送信する処理は入れていません。ホスティング先に送るのはアプリのファイルだけです。

## 注意
- ゆとシートのURLを直接読み込む機能は、ブラウザの通信制限（CORS）などで安定しないため入れていません。
- iOSのバージョンやブラウザによって、ファイル保存やホーム画面追加の表示が異なる場合があります。
